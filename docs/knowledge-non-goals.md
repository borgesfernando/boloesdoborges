# Knowledge Dataset — não objetivos da v1 fundacional

Esta versão não pretende:

- ser um chatbot completo;
- substituir busca semântica/RAG;
- armazenar conversas;
- decidir identidade de participantes;
- autenticar usuários;
- consultar planilhas privadas;
- efetuar pagamentos;
- registrar apostas;
- calcular probabilidades em tempo real;
- substituir termos, FAQ ou estado operacional;
- responder fatos não presentes em fontes verificáveis;
- criar automaticamente novas intents a partir de mensagens reais sem revisão.

O objetivo é somente estabelecer um contrato seguro e reutilizável para organizar conhecimento conversacional futuro.
