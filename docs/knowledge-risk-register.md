# Knowledge Dataset — registro de riscos

| Risco | Mitigação nesta fundação |
| --- | --- |
| Divergência com FAQ | FAQ preservada como autoridade editorial + teste de autoridade |
| Estado desatualizado em resposta | `dynamic/hybrid` + resolver + `operational_state` |
| Alegação indevida de IA/probabilidade | guardrails sensíveis |
| Promoção enganosa por histórico | guardrails e política histórica |
| Exposição de dados financeiros/pessoais | proibição documental + scanner conservador + intent human |
| Ambiguidade entre intents | IDs estáveis + exemplos únicos entre intents |
| Quebra de consumidores existentes | nenhuma integração/wiring nesta PR |
| Mudança incompatível silenciosa | VERSION + schemaVersion |
| Novo site divergir da FAQ | workflow atual de sync permanece intacto |
| Crescimento sem governança | checklist, matriz de requisitos e ADR |
